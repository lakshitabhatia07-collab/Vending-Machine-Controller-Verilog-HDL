# Vending-Machine-Controller-Verilog-HDL
Vending Machine Controller – FSM Design (Verilog HDL)
Overview :This project involves the design and implementation of a Finite State Machine (FSM) for a Vending Machine Controller using Verilog HDL. The controller is designed to handle real-world logic for accepting specific currency denominations and dispensing items based on a programmed price.
Technical Specifications:Target Price: Rs 15
Accepted Denominations: Rs 5and Rs 10
FSM Type: Moore MachineOutputs: Item Dispense Signal and Change Return (Rs 5)🏗 Finite State Machine (FSM) LogicThe system transitions through states based on the accumulated balance. If the user inputs more than the required amount (e.g., two Rs 10 coins for a Rs 15 item), the machine logic triggers a "Change" state to return the surplus.State Descriptions:StateBalanceActionIDLERs 0Waiting for inputS5Rs 5Waiting for more coinsS10Rs 10Waiting for more coinsS15Rs 15Dispense Item (No change)S20Rs 20Dispense Item + Return Rs 5 Change💻 Implementation DetailsThe project is divided into two main modules:Design Module (vending_machine.v): Contains the sequential and combinational logic for state transitions and outputs.Testbench (vending_machine_tb.v): A simulation environment that mimics a user inserting different combinations of coins to verify the logic.🚀 How to SimulateCopy the code from vending_machine.v and vending_machine_tb.v.Paste them into an HDL simulator like Vivado, ModelSim, or the web-based EDA Playground.Run the simulation to observe the dispense and change signals in the waveform viewer.Key Skills Demonstrated:Digital Logic Design & RTL CodingFinite State Machine (FSM) OptimizationHardware Description Languages (Verilog)Testbench writing and Waveform AnalysisDescribe the logic.
