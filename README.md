# Verilog HDL Digital Design Portfolio

Welcome to my digital logic design portfolio. This repository contains various hardware description language (HDL) projects, ranging from Finite State Machines (FSM) to Memory Architectures.

## 📂 Project Directory

### 1. [Vending Machine Controller](./Vending_Machine)
**Key Concepts:** FSM Design, Moore Machine, Combinational & Sequential Logic.
* **Description:** An FSM-based controller that accepts Rs 5 and Rs 10 coins to dispense an item worth Rs 15.
* **Features:** Handles change return logic and synchronous resets.

### 2. [Dual Port RAM](./Dual_Port_RAM)
**Key Concepts:** Memory Arrays, Simultaneous Access, Synchronous Logic.
* **Description:** A 64x8-bit memory module that allows two independent ports to read and write simultaneously.
* **Features:** Conflict-free addressing and full testbench verification.
